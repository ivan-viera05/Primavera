# Primavera 🌻💛

Un regalo web interactivo y romántico para celebrar el **Día de la Primavera** y la tradición de regalar **flores amarillas**.

Incluye una carta de amor interactiva en pergamino, efectos visuales de pétalos dorados y la canción ***Running Home to You*** de Barry Allen (Grant Gustin / *The Flash*).

---

## ✨ Características Principales

- 💌 **Sobre 3D Interactivo**: Con sello de cera de girasol y animación realista de apertura.
- 📜 **Carta de Amor**: Pergamino con tipografía caligráfica, borde ornamental y dedicatoria personalizada.
- 🌻 **Lluvia de Pétalos en Canvas**: Animación física de pétalos dorados flotantes y destellos de polen.
- 💐 **Ramo Virtual Eterno**: Flores amarillas interactivas que nacen y florecen al tocar la pantalla.
- ⚡ **Canción Especial**: Reproductor temático de vinilo con *Running Home to You* de Barry Allen.
- 💛 **Pétalos Secretos**: Tarjetas interactivas con razones y mensajes románticos al hacer clic.
- 📱 **100% Responsivo**: Diseñado para verse perfecto tanto en celulares como en computadoras.
